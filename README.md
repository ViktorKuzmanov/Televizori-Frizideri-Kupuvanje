# Телевизор и фрижидер: споредба на цени

Едноставна веб-страница (за мобилен и компјутер) за избор на **телевизор** и **фрижидер**. Ги споредува цените од **A1, Нептун, Сетек и Техномаркет**. A1 е посебно означен, затоа што таму имам попуст. Секоја цена се зачувува **со датум**, за да се спореди денешната цена со цената на **Black Friday** и да се види колку е вистинскиот попуст.

🌐 Страница: https://viktorkuzmanov.github.io/Televizori-Frizideri-Kupuvanje/

## Буџет и барања
| | Буџет | Што е важно |
|---|---|---|
| 📺 Телевизор | 10.000 – 23.000 ден. | најдобра слика (QLED/Mini LED), AirPlay 2, Google Cast |
| 🧊 Фрижидер | до 27.000 ден. | комбиниран, NoFrost, мала потрошувачка на струја |

Буџетите се во `data/notes.json` → `budgets`.

## Структура
```
index.html                 страницата (ги чита JSON датотеките, нема build)
scripts/fetch_prices.py    ги повлекува цените од сите продавници (само Python 3)
scripts/setec_collect.js   собирач за Сетек, се извршува во прелистувач
data/prices.json           сите производи + историја на цени по датум (за страницата)
data/snapshots/<датум>.json  ЦЕЛОСНА снимка за секој ден (резервна копија, никогаш не се брише)
data/manual/setec-*.tsv    цени од Сетек (првата линија е датумот)
data/notes.json            рачни забелешки по модел: AirPlay/Cast, тип на фрижидер, препораки ⭐, буџети
```

## Продавници
| Продавница | Како се земаат цените | Која цена |
|---|---|---|
| A1 | автоматски | пониска цена (изгледа со тарифа и договор), а `regular` = без тарифа |
| Нептун | автоматски | HaPPy цена (или редовна) |
| Техномаркет | автоматски | SMART цена (со SMART картичка) |
| Сетек | преку прелистувач (`setec_collect.js`) | Клуб цена (со Сетек клуб картичка) |

Сетек ги вчитува цените со JavaScript, па Python не може да ги прочита директно. Затоа Claude ја отвора страницата на Сетек во прелистувач, ја извршува `setecCollect(...)` и резултатот го зачувува во `data/manual/setec-tv.tsv` и `setec-fridge.tsv`.

Ист модел од различни продавници се поврзува по **кодот на моделот** (на пр. `55PUS7810`, `RB34C600ES9`). Затоа на страницата секој модел има една картичка со цените од сите продавници.

## Како да ги ажурирам цените (на пр. за Black Friday)
Кажи му на Claude: **„повлечи ги цените за денес и спореди ги“**. Claude ќе:
1. ги собере цените од Сетек во прелистувач и ќе ги зачува во `data/manual/setec-*.tsv` со денешен датум,
2. ќе изврши:
   ```bash
   python3 scripts/fetch_prices.py --label "Black Friday"
   ```
3. ќе направи commit и push (`git add data && git commit && git push`),
4. ќе ти каже кои производи поевтиниле и за колку, во споредба со претходниот датум.

На страницата, горе изберете **„Цени од … до …“**, на пр. 15.11.2026 → Black Friday. Покрај секоја продавница пишува ▼ колку поевтинило или ▲ колку поскапело.

## Мои производи (листа за следење)
Кажи му на Claude кој модел да го додаде. Во `data/notes.json`, кај моделот, се става `"watch": true`. На страницата се означени со 👀 и се прикажуваат и кога се надвор од буџетот.

> На 15.11 скриптата за Техномаркет погрешно читала дел од цените (прв производ во ред). Поправено на 25.11. Старите цени што не може да се потврдат се означени со `unverified` во `data/prices.json`.

## Каде се чуваат податоците (резервна копија)
- **Локално**, на компјутерот, во оваа папка: `data/snapshots/2026-11-15.json` итн. Секој ден е посебна датотека и старите не се бришат. Ако продавницата ја смени или избрише цената, нашата стара цена останува.
- **На GitHub**: секое ажурирање е посебен commit, па и историјата е зачувана.
- Ако некоја продавница ја смени страницата и скриптата не најде производи, скриптата прекинува со грешка и **ништо не пребришува**.

## Забелешки
- AirPlay/Google Cast ги нема на страниците на продавниците. Тие се внесени рачно во `data/notes.json` (по модел), или според брендот (`brandDefaults`). „?“ значи непотврдено.
- Се чуваат само ТВ до 45.000 ден. и фрижидери до 50.000 ден. (`CAP` во скриптата).
- Страницата е хостирана на GitHub Pages од гранката `main`.
