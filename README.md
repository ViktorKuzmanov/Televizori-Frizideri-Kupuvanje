# Телевизор и фрижидер: следење цени од A1

Едноставна веб-страница за избор и купување на **телевизор** и **фрижидер** од [A1 Македонија](https://www.a1.mk/webshop/mk/tv/shop). Таму имам попуст. Цените се зачувуваат **со датум**, за да ги споредам денешните цени со цените на **Black Friday** и да видам колку е вистинскиот попуст.

🌐 Страница: https://viktorkuzmanov.github.io/Televizori-Frizideri-Kupuvanje/

## Буџет и барања
| | Буџет | Што е важно |
|---|---|---|
| 📺 Телевизор | 10.000 – 23.000 ден. | најдобра слика (QLED/Mini LED), AirPlay 2, Google Cast |
| 🧊 Фрижидер | до 27.000 ден. | комбиниран, NoFrost, мала потрошувачка на струја |

Буџетите се во `data/notes.json` → `budgets`.

## Структура
```
index.html               страницата (ги чита JSON датотеките, нема build)
scripts/fetch_prices.py  ги повлекува моменталните цени од A1 (само Python 3, без пакети)
data/prices.json         сите производи + историја на цени по датум
data/snapshots/*.json    сурова снимка за секој датум
data/notes.json          рачни забелешки: буџети, AirPlay/Cast, тип на фрижидер, препораки (⭐)
```

## Како да ги ажурирам цените (на пр. за Black Friday)
Кажи му на Claude: **„повлечи ги цените за денес и спореди ги“**. Или рачно:

```bash
python3 scripts/fetch_prices.py --label "Black Friday"
git add data && git commit -m "Цени $(date +%F)" && git push
```

Скриптата:
1. ги зема страниците за телевизори и фрижидери од A1,
2. зачувува `data/snapshots/<датум>.json`,
3. ја додава новата цена со датум во историјата во `data/prices.json` (старите цени остануваат).

На страницата, горе изберете **„Спореди цени од … до …“**, на пр. 15.11.2026 → датумот на Black Friday. За секој производ ќе пишува колку денари и колку % е поевтин или поскап.

## Значење на цените
- **Цена во A1** е цената на картичката во A1 онлајн продавницата (`fullPrice`).
- **Редовна цена** е основната цена (`defaultBasePrice`).
- **На рати** е месечна рата × број на рати.

> Проверете во A1 дали „Цена во A1“ важи за еднократно плаќање или само со A1 тарифа.

## Забелешки
- AirPlay/Google Cast ги нема на страницата на A1. Тие се внесени рачно во `data/notes.json`. Ако нешто не е потврдено, стои „?“.
- Ако A1 ја смени страницата и скриптата не најде производи, таа прекинува со грешка и ништо не пребришува.
- Страницата е хостирана на GitHub Pages од гранката `main`.
